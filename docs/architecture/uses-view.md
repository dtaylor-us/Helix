# Uses View

- Web uses API routes in /api/v1.
- Today use case uses active experiment, reflection history, and suggestion history.
- Reflection creation uses deterministic suggestion generation after save.
- Knowledge use case stores beliefs under transformations and evidence under beliefs.
- Evidence provenance may point to manual notes or existing reflections.
- Weekly retrospective draft uses the last seven days of reflections and deterministic guidance text.
- Wisdom use case stores accepted entries with explicit source links to reflection, evidence, or retrospective records.
- Search use case aggregates structured keyword matches across reflection, belief, evidence, retrospective, and wisdom records.
