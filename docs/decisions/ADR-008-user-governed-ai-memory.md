# ADR-008 User-governed AI memory

- Status: Accepted
- Date: 2026-07-26

## Context
AI-derived interpretation can be wrong and should not become fact silently.

## Decision
Memory lifecycle requires proposal, review, and explicit user acceptance.

## Alternatives
- Automatic persistence of AI-derived memory.

## Consequences
Higher trust and controllability.

## Risks
More UX complexity in memory workflows.

## Reconsideration Triggers
None.

## Related Requirements
HELIX-BR-003, HELIX-AI-002
