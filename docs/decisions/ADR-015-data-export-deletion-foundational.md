# ADR-015 Data export and deletion as foundational capabilities

- Status: Accepted
- Date: 2026-07-26

## Context
Helix emphasizes user ownership and recoverability of personal records.

## Decision
Treat export and deletion capabilities as foundational roadmap work.

## Alternatives
- Defer portability and deletion to late phase.

## Consequences
Higher trust and better recovery posture.

## Risks
Additional implementation complexity early in lifecycle.

## Reconsideration Triggers
None.

## Related Requirements
HELIX-FR-006, HELIX-NFR-002
