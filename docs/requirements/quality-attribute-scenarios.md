# Quality Attribute Scenarios

- HELIX-QAS-RESP-001: App shell appears in <=2s on typical device with warm cache.
- HELIX-QAS-RESP-002: Non-AI interactions show feedback <=200ms and complete <=1s under normal conditions.
- HELIX-QAS-AI-001: AI calls show progress and allow cancellation; timeout degrades gracefully.
- HELIX-QAS-REL-001: Confirmed reflection persists across single process restart.
- HELIX-QAS-OFF-001: User can draft reflection while offline with unsynced state indicator.
- HELIX-QAS-PRIV-001: Personal content excluded from default logs/telemetry.
- HELIX-QAS-ACC-001: Core workflows are keyboard accessible and screen-reader compatible.
