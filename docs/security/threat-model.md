# Threat Model Summary

Primary threat scenarios:
1. Unauthorized access to personal growth records.
2. Sensitive content leakage through logs/telemetry.
3. External AI provider disclosure without consent.
4. Data loss from operational failure.

Mitigations:
- API boundary and auth integration point.
- Logging prohibition for reflective content.
- Explicit AI provider configuration and consent.
- Backup/export/restore roadmap commitments.
